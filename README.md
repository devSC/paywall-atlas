# WALL / ATLAS — 付费墙浏览设计预览

打开 `index.html`，或在本目录启动 `python3 -m http.server 8765 --bind 127.0.0.1` 后访问 http://127.0.0.1:8765。

## 浏览方式

每个 App 一行，名称链接 App Store（由真实 App ID 生成）。下方以视频为第一项，后接完整截图序列，横向滚动。分类、搜索、收藏与排序用于缩小范围；截图可放大查看。

## 当前数据范围

- 来源：https://www.paywallpro.app/zh/paywalls
- 仅首屏 12 个真实应用样本，137 张流程截图，12 个视频地址。
- 页面只引用原始图片和视频链接，浏览时通过来源 CDN 按需加载；需要联网。仓库不保存图片或视频文件。
- 截图序列含引导、付费墙及应用内页面；封面由人工查看后选择，未把所有截图标注为付费墙。
- 全量归档尚未开始。目标从 2026-02-01 起，日期筛选口径（收录时间或截图更新日期）待确认。
- manifest.json 保留来源地址、App ID、分类、原始日期及远程资源链接。

## 下一阶段

## 获取和运行

```bash
gh repo clone devSC/paywall-atlas
cd paywall-atlas
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765；服务需要保持运行。也可以直接打开克隆目录中的 index.html，无需构建或安装依赖。

GitHub 仓库用于保存源码；当前未启用在线网站托管。
